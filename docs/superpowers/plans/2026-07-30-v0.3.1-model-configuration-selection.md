# 琅嬛 v0.3.1 模型配置与选择 Implementation Plan

> 状态：已于 2026-07-30 按本计划完成实现；文中的 checkbox 保留为逐步复现与审查清单。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 交付平台共享与 Workspace 自有的 Embedding Provider/Model 配置、AES-GCM 凭证保存、真实连接测试，以及知识库显式绑定 `embedding_model_id` 的完整后端和 Web Console 闭环。

**Architecture:** 使用 `model_providers + models` 两层持久化结构；application service 负责作用域、生命周期和引用规则，Provider Registry 负责把严格 JSON 解码成五种 typed config 并构造 Eino 原生 Embedder。知识库创建/换模通过专用 `KnowledgeBaseModelBinder` 在同一数据库事务内复核模型可见性和可用性；v0.3.1 只测试连接，不把 Embedder 接入 `document_index`。

**Tech Stack:** Go 1.26、Gin、GORM、PostgreSQL、AES-256-GCM、CloudWeGo Eino/Eino Ext、React 19、TypeScript 7、TanStack Router/Query、React Hook Form、Zod、shadcn/ui、Biome、Vitest Browser。

## Global Constraints

- 严格 Red → Green → Refactor；每项生产行为先运行一个能够说明缺失行为的失败测试，再写最小实现。
- v0.3.1 只开放 `embedding`；数据表可保存未来的 `llm`、`rerank`，但当前 Service/API/UI 不创建或选择它们。
- Provider Registry 只注册 `openai`、`ark`、`ollama`、`dashscope`、`tencentcloud`；`qianfan` 返回 `unsupported_provider`，不得写进程级全局凭证。
- 数据库不得为 `provider` 增加枚举 CHECK；Provider 合法性只由 application Registry 判断。
- Embedding 维度只允许 `798`、`1024`、`2048`、`3584`；application/Web 默认 `1024`，API 创建 Model 仍要求显式提交维度。
- 每个 KnowledgeBase 必须显式保存非空 `embedding_model_id`；删除 `embedding_dimension`，不创建占位模型、不回填、不做同步迁移。
- `scope=platform` 只能由 `platform_admin` 管理；`scope=workspace` 由该 Workspace 的 admin/owner 管理；member 可查看并在创建知识库时选择。
- Workspace 可见范围始终是“平台共享 + 当前 Workspace 自有”；错误 Workspace 或错误作用域路由统一 404。
- Ollama 只允许平台作用域；Workspace 自定义 endpoint 只允许 SSRF-safe 公网 HTTPS，且重定向和实际拨号都必须防 DNS rebinding。
- 凭证使用 AES-256-GCM，密文格式固定为 `[version=1][12-byte nonce][ciphertext+tag]`，AAD 固定为 `model-provider:<uuid>`。
- 唯一密钥来自 `config.yaml` 的 `credentials.encryption_key`；必须是 Base64 编码的 32 字节，空值或非法值使运行时启动失败；不提供环境变量、key 文件、key ID 或自动轮换。
- Provider config、credentials、Model parameters 必须经 Provider 专属 struct 严格解码；API 不提供 JSON 编辑器，响应、日志、Query cache、URL 与浏览器存储不出现凭证明文。
- Provider/Model 只使用 `active|disabled`，不使用软删除；有下级 Model 的 Provider 和被 KnowledgeBase 引用的 Model 返回 409。
- 被引用 Model 的 `provider_id/type/model_name/dimensions` 不可修改；停用不改变已有绑定，也不自动 fallback。
- 连接测试固定输入 `langhuan embedding connection test`，允许测试 disabled 记录，不持久化文本、向量或测试结果。
- domain 不带 JSON/GORM/Eino 类型；JSONB 使用现有 `JSONMap` 和显式 codec；所有 I/O 透传 `context.Context`。
- v0.3.1 不调用文档 Embedding、不写 `chunk_embeddings`、不实现搜索、reindex、LLM、Rerank、千帆、YAML 模型目录或客户端缓存。
- `web/src/routeTree.gen.ts` 只能由 TanStack Router 插件生成，禁止手改。
- 每个后端任务 GREEN 后运行 `go test ./... -count=1`；每个前端任务 GREEN 后运行 `pnpm --dir web check && pnpm --dir web test && pnpm --dir web build`。

CREATE TABLE IF NOT EXISTS model_providers (
    id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
    scope text NOT NULL CHECK (scope IN ('platform', 'workspace')),
    workspace_id uuid REFERENCES workspaces(id) ON DELETE CASCADE,
    name text NOT NULL, display_name text NOT NULL DEFAULT '', description text NOT NULL DEFAULT '',
    provider text NOT NULL, config jsonb NOT NULL DEFAULT '{}'::jsonb,
    credentials_ciphertext bytea, status text NOT NULL DEFAULT 'active' CHECK (status IN ('active', 'disabled')),
    created_by uuid REFERENCES users(id) ON DELETE SET NULL,
    created_at timestamptz NOT NULL DEFAULT now(), updated_at timestamptz NOT NULL DEFAULT now(),
    CONSTRAINT model_providers_workspace_check CHECK (
        (scope = 'platform' AND workspace_id IS NULL) OR
        (scope = 'workspace' AND workspace_id IS NOT NULL)
    )
);
CREATE UNIQUE INDEX uq_model_providers_platform_name ON model_providers(lower(name)) WHERE scope='platform';
CREATE UNIQUE INDEX uq_model_providers_workspace_name ON model_providers(workspace_id, lower(name)) WHERE scope='workspace';

CREATE TABLE IF NOT EXISTS models (
    id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
    provider_id uuid NOT NULL REFERENCES model_providers(id) ON DELETE RESTRICT,
    name text NOT NULL, display_name text NOT NULL DEFAULT '', description text NOT NULL DEFAULT '',
    type text NOT NULL CHECK (type IN ('embedding', 'llm', 'rerank')),
    model_name text NOT NULL, dimensions integer, parameters jsonb NOT NULL DEFAULT '{}'::jsonb,

    created_by uuid REFERENCES users(id) ON DELETE SET NULL,
    created_at timestamptz NOT NULL DEFAULT now(), updated_at timestamptz NOT NULL DEFAULT now(),
    CONSTRAINT models_dimensions_check CHECK (
      (type='embedding' AND dimensions IN (798,1024,2048,3584)) OR

    )
);
CREATE UNIQUE INDEX uq_models_provider_type_name ON models(provider_id, type, lower(name));
