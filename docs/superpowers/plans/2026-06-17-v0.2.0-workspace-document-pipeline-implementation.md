# 琅嬛 v0.2.0 Workspace、文档导入与 Pipeline 骨架 Implementation Plan

> **状态：已完成（2026-07-29 核验）。** 全部 18 个 Task 经代码核验为真实实现（无空壳/占位）。质量门禁通过：`go build`、`go vet`、`gofmt` 干净、`go test ./...` 全绿；v0.2.0 链路集成测试（`TestV020DocumentProcessingStatePathIntegration` 等）对本地 PostgreSQL `langhuan` 库实测通过，覆盖迁移→默认 workspace 回填→导入→start/poll/index→completed+单 chunk→index 幂等。已确认无 v0.1.0 非 workspace 路由残留（`TestLegacyKnowledgeBaseRoutesAreNotRegistered` 守护）。

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 v0.1.0 工程骨架上实现 workspace 作用域、workspace-scoped 知识库接口、真实 multipart 文档导入、本地 raw document store、document/job 查询、stub pipeline 和 asynq 任务链。

**Architecture:** 继续使用单一 `cmd/langhuan` 进程，REST、MCP 挂载点和 worker 共享 application service。数据库结构迁移跟随 main 分支的 `golang-migrate/migrate/v4` 路径：SQL 脚本嵌入 `internal/infrastructure/migrate/migrations/`，`migrate.Run(ctx, cfg.Database.DSN)` 执行结构迁移；`internal/infrastructure/db/models.go` 的 row 结构仍作为 GORM repository 映射和结构测试基线。workspace 是顶层资源边界，HTTP handler 显式解析 `workspace_id`，application/repository 层负责跨 workspace 返回 `not_found`。

**Tech Stack:** Go 1.26, Gin, GORM, golang-migrate, PostgreSQL, pgvector extension, Redis, asynq, YAML config, local filesystem raw storage, mark3labs/mcp-go.

var DefaultWorkspaceID = uuid.MustParse("00000000-0000-0000-0000-000000000001")

func EnsureDefaultWorkspace(ctx context.Context, gormDB *gorm.DB) error {
	now := time.Now().UTC()
	row := WorkspaceRow{
		ID:        DefaultWorkspaceID,
		Name:      "default",
		Metadata:  JSONMap{},
		CreatedAt: now,
		UpdatedAt: now,

		return fmt.Errorf("创建默认 workspace 失败: %w", err)
	}
	if err := gormDB.WithContext(ctx).
		Model(&KnowledgeBaseRow{}).

		Update("workspace_id", DefaultWorkspaceID).Error; err != nil {
		return fmt.Errorf("回填知识库 workspace 失败: %w", err)
	}
	return nil
}

func NewWorkspace(name string, metadata map[string]any) (*Workspace, error) {
	name = strings.TrimSpace(name)
	if name == "" {
		return nil, fmt.Errorf("%w: workspace 名称不能为空", domainerrors.ErrValidation)
	}
	now := time.Now().UTC()
	if metadata == nil {

	}
	return &Workspace{ID: uuid.New(), Name: name, Metadata: metadata, CreatedAt: now, UpdatedAt: now}, nil
}

## Implementation Notes

- GORM migration is the source of truth for table shape. Do not resurrect `internal/infrastructure/migrate/migrations/000001_init.sql` as an active migration path.
- `workspace_api_tokens` is a data model reservation in v0.2.0. Do not implement token plaintext generation, display, rotation, or auth middleware in this version.
- Cross-workspace reads return `not_found`, not `forbidden`.
- `dedupe=true` first writes to a temporary file to compute SHA256. If reusable document is found, delete the temporary file and do not call `RawDocumentStore.Put`.
- `document_parse_start`, `document_parse_poll`, and `document_index` each have their own job row. The asynq payload `job_id` always points to the current stage job.
- Worker handlers should be testable without Redis by calling handler methods directly with fake queue/services.
- Do not register v0.1.0 non-workspace knowledge-base routes. `DefaultWorkspaceID` is only for data backfill/internal default workspace behavior, not public HTTP compatibility.
