# v0.4.0 Review Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复 v0.4.0 评审确认的八类后端、检索、数据库、HTTP 和 Web Console 问题。

**Architecture:** 保持 v2 的 Generation 和 Workspace transaction 为唯一生效边界；删除与该边界冲突的 v1 捷径。所有行为修改先以最小回归测试进入 RED，再实施 GREEN，最后做职责内清理。

**Tech Stack:** Go 1.26、Gin、GORM、PostgreSQL/pgvector、testcontainers、React 19、TanStack Query、Vitest、Biome。

## Global Constraints

- 所有数据库测试只使用测试运行时创建并销毁的 `pgvector/pgvector:pg16` 容器。
- Domain 不包含 JSON/GORM tag；HTTP 只做协议转换。
- Workspace 业务写入必须进入 `WorkspaceTxRunner.WithinWorkspace` 并始终使用 tx。
- 不恢复 `knowledge_bases.embedding_model_id`；模型切换只走 Generation。
- 每个生产代码改动必须先观察到对应测试因缺少该行为而失败。
