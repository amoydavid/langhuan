# 琅嬛 v0.1.0 工程骨架实现计划

> **状态：已完成（2026-07-29 核验）。** 全部 14 个 Task、所有 step 勾选框与自评清单均经代码核验并通过（`go test ./...`、`go vet ./...`、`gofmt` 干净；集成测试对本地 PostgreSQL `langhuan` 库实测通过）。已知实现偏差见 Task 6（迁移引擎由 GORM AutoMigrate 改为 golang-migrate）。

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建琅嬛 v0.1.0 的可运行 Go 1.26 服务骨架，完成 YAML 配置、PostgreSQL/Redis/asynq 接入、领域模型、迁移、基础 REST、MCP 挂载点和 worker smoke。

**Architecture:** 使用单一入口 `cmd/langhuan` 启动 REST、MCP 和 worker。核心代码按 interfaces/application/domain/ports/adapters/infrastructure 分层，domain 不依赖框架，application 只依赖 domain 和 ports，HTTP/MCP/worker 通过 application service 访问能力。

**Tech Stack:** Go 1.26, Gin, GORM, PostgreSQL, pgvector extension, Redis, asynq, YAML config, mark3labs/mcp-go.

```go
package config

import (
	"errors"
	"fmt"
	"os"

	"gopkg.in/yaml.v3"
)

type Config struct {
	Server   ServerConfig   `yaml:"server"`
	Database DatabaseConfig `yaml:"database"`
	Redis    RedisConfig    `yaml:"redis"`
	Log      LogConfig      `yaml:"log"`
}

type ServerConfig struct {
	HTTPAddr  string `yaml:"http_addr"`
	RunHTTP   bool   `yaml:"run_http"`
	RunWorker bool   `yaml:"run_worker"`
}

type DatabaseConfig struct {
	Driver string `yaml:"driver"`
	DSN    string `yaml:"dsn"`
}

type RedisConfig struct {
	Addr     string `yaml:"addr"`
	Password string `yaml:"password"`
	DB       int    `yaml:"db"`
}

type LogConfig struct {
	Level string `yaml:"level"`
}

func Load(path string) (*Config, error) {
	if path == "" {
		path = "config.yaml"
	}
	data, err := os.ReadFile(path)
	if err != nil {
		return nil, fmt.Errorf("读取配置文件失败: %w", err)
	}
	var cfg Config
	if err := yaml.Unmarshal(data, &cfg); err != nil {
		return nil, fmt.Errorf("解析 YAML 配置失败: %w", err)
	}
	cfg.applyDefaults()
	if err := cfg.validate(); err != nil {
		return nil, err
	}
	return &cfg, nil
}

func (c *Config) applyDefaults() {
	if c.Server.HTTPAddr == "" {
		c.Server.HTTPAddr = ":8080"
	}
	if c.Database.Driver == "" {
		c.Database.Driver = "postgres"
	}
	if c.Redis.Addr == "" {
		c.Redis.Addr = "127.0.0.1:6379"
	}
	if c.Log.Level == "" {
		c.Log.Level = "info"
	}
}

func (c *Config) validate() error {
	if c.Database.DSN == "" {
		return errors.New("database.dsn 不能为空")
	}
	if c.Redis.Addr == "" {
		return errors.New("redis.addr 不能为空")
	}
	return nil
}
```

```go
package value

type ChunkingConfig struct {
	ChunkSize    int `json:"chunk_size"`
	ChunkOverlap int `json:"chunk_overlap"`
}

func DefaultChunkingConfig() ChunkingConfig {
	return ChunkingConfig{ChunkSize: 512, ChunkOverlap: 80}
}

func (c ChunkingConfig) Normalize() ChunkingConfig {
	if c.ChunkSize <= 0 {
		c.ChunkSize = 512
	}
	if c.ChunkOverlap < 0 {
		c.ChunkOverlap = 0
	}
	if c.ChunkOverlap == 0 {
		c.ChunkOverlap = 80
	}
	return c
}
```

```go
package model

import (
	"errors"
	"strings"
	"time"

	"github.com/google/uuid"

	"github.com/dajee/langhuan/internal/domain/value"
)

type KnowledgeBase struct {
	ID                 uuid.UUID
	Name               string
	Description        string
	EmbeddingDimension int
	ChunkingConfig     value.ChunkingConfig
	Metadata           map[string]any
	CreatedAt          time.Time
	UpdatedAt          time.Time
}

func NewKnowledgeBase(name, description string, dimension int, chunking *value.ChunkingConfig, metadata map[string]any) (*KnowledgeBase, error) {
	name = strings.TrimSpace(name)
	if name == "" {
		return nil, errors.New("知识库名称不能为空")
	}
	if dimension <= 0 {
		return nil, errors.New("embedding 维度必须大于 0")
	}
	cfg := value.DefaultChunkingConfig()
	if chunking != nil {
		cfg = chunking.Normalize()
	}
	now := time.Now().UTC()
	return &KnowledgeBase{
		ID:                 uuid.New(),
		Name:               name,
		Description:        description,
		EmbeddingDimension: dimension,
		ChunkingConfig:     cfg,
		Metadata:           metadata,
		CreatedAt:          now,
		UpdatedAt:          now,
	}, nil
}
```

## 子代理拆分建议

如果使用子代理并行实现，建议拆分为三个互不冲突的写入范围：

- 子代理 A：`internal/domain/**`、`internal/ports/**`、`internal/infrastructure/migrate/**`。
- 子代理 B：`internal/infrastructure/config/**`、`internal/infrastructure/logger/**`、`internal/infrastructure/db/**`、`internal/application/**`。
- 子代理 C：`internal/interfaces/**`、`internal/adapters/queue/**`、`cmd/langhuan/**`。

每个子代理都必须遵守：

- 不回滚他人修改。
- 不提交 `config.yaml`。
- commit message 可使用 `feat:`、`chore:` 等前缀，描述正文以中文为主。
- 不实现 v0.2.0 之后的功能。
