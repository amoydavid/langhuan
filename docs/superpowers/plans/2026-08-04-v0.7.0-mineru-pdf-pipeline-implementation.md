# 琅嬛 v0.7.0 MinerU Cloud PDF 解析与资产归档实现计划

> **给执行代理：** 执行本计划时使用 superpowers:subagent-driven-development（若环境支持 subagent），否则使用 superpowers:executing-plans。步骤用 checkbox（`- [x]`）跟踪。执行前必读对应设计文档 `docs/superpowers/specs/2026-08-04-v0.7.0-mineru-pdf-pipeline-design.md`。

**目标：** 在 v0.6.0 的 workspace 文档导入、`DocumentRevision → ChunkSet → Chunk → ChunkRevision` 事实模型、Embedding/混合检索、Web Console 和 Workspace API Key/MCP 之上，新增 S3-compatible 可切换存储、MinerU Cloud PDF parser 适配器（worker 层异步）、AssetResolver 图片归档、ParserProvider 凭据能力域，并接入现有 chunk/embed/index 流水线与 Web Console。

**架构：** 继续单进程 `cmd/langhuan`。保持同步 `DocumentParser` 接口不变，为 MinerU 新增 `AsyncDocumentParser` 可选接口，worker 的 `document_parse_start/poll` 通过类型断言走异步分支。MinerU token 复用 `model_providers` 表（AES-GCM 加密），应用层引入 ParserProvider 能力域与 embedding 能力域解耦。PDF 解析产出的 normalized Markdown 自动进入现有 `document_index`。

**技术栈：** Go 1.26、Gin、GORM（读映射）、golang-migrate（写 schema）、PostgreSQL+pgvector、Redis/asynq、AWS SDK for Go v2（S3）、YAML config；UUIDv7 用 `github.com/google/uuid`。
