# v1.3.0 Web 内容源（知识库内多源爬取）Implementation Plan

> **For agentic workers:** Steps use checkbox (`- [ ]`) syntax for tracking. 设计依据：`docs/superpowers/specs/2026-09-16-v1.3.0-web-source-design.md`（第 4 稿，四轮评审定稿）。

**Goal:** 知识库内新增"网站内容源"（`kb_sources`，一库多源）：页面按三种模式（crawl/sitemap/urls）经四引擎（http/render/firecrawl/jina + auto 升级）抓取为 `kind='web'` 文档，与上传文件混居同一索引；源可独立配置/重跑/启停/删除；Console 用 FAQ 同构的「Web」子 tab（请求列表 → 源详情）管理。

**Architecture:** 复用 `SourceConnector` port 与 `SourceSyncService` 纯函数（diff/cursor/RetryRequired），编排主语从 KB 泛化为源：同步状态（cursor/force latch/last_result）迁到 `kb_sources` 行，飞书路径一行不动；爬取只发生在 asynq worker（全局在飞上限 + 按源推导超时，§9.1）；Console 复用现有条件「Web」子 tab 与 `ContentList kind='web'`。

**Tech Stack:** Go 1.26、Gin、asynq（+standalone 内存队列）、GORM/pgvector、go-rod、go-shiori/go-readability、JohannesKaufmann/html-to-markdown、temoto/robotstxt；React 19 + TanStack Router/Query + RHF + Zod。

## Global Constraints

- **编排主语**：`kb_sources` 行承载 config + sync_cursor/next_sync_at/sync_requested_force/sync_last_result/on_delete；`knowledge_bases.source_type` CHECK **不放宽**（裁决 1）；飞书路径（`ListDueFeishuKBs`、KB 级编排）零改动。
- **执行隔离**（裁决 3）：任何入口不得绕过队列直接爬取；并发 web 源 source_sync ≤ `web_source.max_concurrent_syncs`（默认 2，仅计 web 源任务）；入队 Timeout 按 `min(页数基准×(单页超时+延迟)×2, sync_task_timeout_seconds=4h)` 推导，页数基准：crawl=max_pages / urls=len(urls) / sitemap=500（具名常量）。
- **页面身份**：`external_id = source_uri = NormalizeWebSourceURI(raw)`（新增跟踪参数剥离，包内具名常量）；同 KB 跨源 URL 冲突先到先得（warning `url_owned_by_other_source`）。
- **SSRF 分层**：http 引擎走现有 `NewPublicHTTPSClient` 完整防护；render/provider 前置 host 校验 + 文档明示降级（§6.4），不得声称端到端保证。
- 测试数据库只用临时 docker pgvector/zhparser 容器（AGENTS 5.10）；外部依赖（CDP/firecrawl/jina）一律 fake transport，不发真实网络请求。
- 检索链路零改动 → `make eval` 回归标注"不适用"（无 chunker/RRF/embedding 变更）。
- 新依赖 `go-rod`、`go-shiori/go-readability`、`JohannesKaufmann/html-to-markdown`、`temoto/robotstxt` 经 `go get` 引入、选 7 天前已发布版本；firecrawl/jina 用裸 HTTP client 不引 SDK。

## 验收标准（对照 spec §12.4）

1. 同一 KB：上传文件 + ≥2 种模式网站源共存，页面与文件同场检索命中，页面可按源溯源（`kb_source_id`）
2. 三级增量正确：lastmod/cursor 跳过、304 跳过、hash 未变跳过、变更建 `revision_no+1`；crawl 截断不删文档且 warning 可见
3. `auto` 对静态页不渲染、对 JS-shell 页升级并留痕 `last_engine`；无连接时 warning `possible_js_shell`
4. robots 默认拦截可观测、可关；SSRF http 层完整、render/provider 层按 §6.4 文档化
5. firecrawl/jina/browser 连接密文落库 + 连接测试可用；无凭证 http 源正常工作
6. 源 CRUD/启停/删除幂等、两删除分支正确；跨源冲突先到先得；MCP url 无/多 urls 源拒绝正确；Web 子 tab "有源无页"仍显示；在飞 ≤ `max_concurrent_syncs`、超时推导生效（大 max_pages 不落 30 分钟默认）
7. `go test ./...`、集成测试、`go vet`、`pnpm check/test/build` 全绿
